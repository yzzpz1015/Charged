卫星图跨城迁移判负

卫星图跨城零样本迁移这条线，在 CHARGED 上已可判定为不可行。以下是全部实验、可确定的结论、以及我修正过的判断，供方向定夺。

判决 · 三条可确定的结论
判负

卫星图对充电需求预测没有可用增量。跨城 ρ=0.146（p=0.24，需 ~370 站才显著），被免费元数据 charger_num 的 ρ=0.761 碾压，且叠加后反而变差。

机制

文献中「图像有用」的一个主要来源是站身份记忆：在 station-week 随机划分下，给每个站一个随机数比真卫星图还好用。

定位

城内确实存在一个真实但很弱的信号 ρ≈0.15（解释率 2%）。它的尺度已定位在 380m，但成分只完成排除——不是地理位置，也不是土地利用；剩下最可能指向微观建成形态，尚未直接测量。

DVisionEV 消融的结构性缺口

它的「图像作用」用的是 self-ablation：Table 4 五行全是同一个 PaliGemma-3B，唯一差别是拿掉哪个部件。卫星图的贡献 = VisionEV − w/o Satellite Image。这个设计在控制变量上确实干净，但有三个缺口。

三个缺口
  • 没有纯表格地板。Table 4 里没有任何非视觉模型。而 Full-shot 同档比较下，去图版 3.29 差于 LightGBM 的 2.90——图像的贡献是把这个多模态架构从「不如 GBDT」拉回「和 GBDT 打平」，不是「图像优于表格特征」。
  • Zero 是四档平均，不是单次。4.3.3 说是 20 / 40 / 60 / 80% 站点作训练源的平均，难度跨度 RMSE 3.18–3.98。逐档的 w/o-image 数字未报，无法判断增益落在哪一档。
  • Zero 的增益是尾部驱动。Full/Few 两档 ΔRMSE ≈ ΔMAE（整体平移），Zero 档 ΔRMSE 是 ΔMAE 的 1.79 倍——说明图像让少数站的离谱错误变少，而非普遍提升。1.20 是平均，把这个局部现象摊到了所有站上。

注：我曾拿「去图 4.68」与「LightGBM 4.19」直接比较（差 0.49）——那是四档平均比单档，不成立，已收回。可用的等价比较只有 Full-shot 那一行。

E我修正过的判断

这条线上我犯过并已更正的三处，以及一处数据局限。列出是为了让结论的可信度可被检验。

更正记录
  • 「视野 / 分辨率不是瓶颈，可零成本复现该视角」 —— 错。复现后视野恰是那个从 0 变成 +0.15 的变量，2.5km 全图是零。
  • 「frozen +0.148 是预处理噪声」 —— 错。20 个划分种子 20/20 为正，置换 z≈5.7，是真信号。
  • 「图像 ≈ 土地利用 one-hot，故 VisionEV 的消融虚高」 —— 在 CHARGED 上被证伪（见 E7），不能作为批评。
  • 技术根因：L2 归一化后各站 DINOv2 嵌入的均值方向范数 = 0.886（上限 1.0），真实差异藏在 ~11% 残差里。做此类探针必须用带截距的回归，否则会被共同方向主导而退化成 ρ≈−0.02。
数据局限
  • POI 覆盖度跨城严重不对称：other 占比 LOA 52.9% / MEL 84.6% / JHB 87.0%。跨城的 POI 结论弱，城内结论强。
  • 我用的是 OSM POI 计数，VisionEV 用的是地块土地利用面积标签——「代理的代理」。
  • 分辨率差 8.5 倍：我 1.98 m/px（z16）vs VisionEV 0.23 m/px（z19）。视野对齐了，清晰度没有。若要把否定结论写成论文，这是必须先堵的漏洞。

F待定 · 请学长定夺

01跨城零样本卫星图迁移

CHARGED 上判负，我建议停止推进。信号真实存在但量级 ρ≈0.15、跨城不显著、且被免费元数据完全覆盖——没有可做的增量空间。

02是否转向否定性 / 方法学论文

手上有成体系的否定证据：站身份陷阱（E1）+ 视野敏感（E3）+ 自由元数据碾压（E4）+ 消融结构缺口（D）。故事是「文献为何会看错卫星图的作用」。前提是先花一轮补 z19 堵分辨率漏洞。

03还是换问题

若认为否定性结论不适合目标期刊，则卫星这条线整体搁置，回到主线（Kairos L2 / Agent 方向）。

04VisionEV 逐档复现

可复现它的 20/40/60/80% 划分并补上逐档 w/o-image 数字，看 1.20 增益落在哪一档。这是可做的验证，但验证的是它的结论，不是我们的方向——优先级取决于 02 是否推进。
