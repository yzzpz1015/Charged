# 概率预测阶段总结（2026-10-20）

**一句话**：五城 EV 充电概率预测上，简单“逐站分位头”（③）稳定小胜“点预测 + 残差池”（①）；两种扩散（④ 整块 CSDI、⑤ 吸收态 zidiff）都输。输的原因不是没调好，而是零原子、欠离散、门控 precision 三个结构问题。现有证据足够撑一篇“方法对比 + 失败机理”的论文，继续换扩散花式的性价比很低。

---

## 1. 出发点

- 点预测只给一个数；充电量有大量**真实 0**、重尾、站间相关，需要分布预测。
- 学长原方向：魔改 Diffusion，一次输出 `[站 × H]` 整块场景，用 CRPS_sum 衡量站间联合。
- 先搭统一评测，否则头对头没有意义：
  - 停摆行（该小时 >80% 站同时为零）丢弃；剩余可用行按时间计数切 train 2 / valid 1 / test 3。
  - clean mask 去掉注入式直线段（JHB 52%、SPO 42% 的窗口受影响）。
  - 只用**训练期**统计筛死站/常数平台站，避免泄漏。
  - 五城：LOA / JHB / MEL / SPO / SZH；AMS 因测试期 95.9% 站冻结，单列、不参与横向平均。
- 指标：
  - 一开始 CRPS_sum 第一；实测后**降级为对照**，改用 **crpsΣ（单站边际）主判**。
  - 扩散类必须另报**条件 CRPS**（只算真值 > 0 的格子），否则真零格会被“门控直接写 0”白送满分。
  - PICP / MPIW 作校准与宽度诊断。

---

## 2. 做了什么

| 做法 | 内容 | 角色 |
|---|---|---|
| ① 点预测 + 残差池 | Kairos 点预测（或 PatchTST）+ 验证期/滚动 28 天残差自助采样 | 简单强基线 |
| ③ 分位头 | 冻结 Kairos 主干，逐站输出 99 个分位数，pinball loss | 主力方法 |
| ④ 整块扩散 | CSDI 一次生成 `[站 × H]`，外加 on/off 分类器 | 学长指定的扩散路线 |
| ⑤ 吸收态扩散 | zidiff：生死（0/非 0）与数值在同一个扩散网络里联合学 | 对④的结构修正 |
| 参照 | PatchTST 点预测 + 同一个残差池 | 检验“TSFM 主干是否关键” |

另外做了一批**不训练或轻量**的探针：零原子校准、门控换原子、逐站仿射校准、残差回归、正值幅度头、上尾校准、跨站残差相关。

- ③ 相对 ①：H=24 −5.5%，H=48 −2.5%，H=72 −3.1%；4/5 城小胜，SZH 基本打平。

## 4. 六个重要结论

### 结论 1：③ 是当前最好的，但只是“小胜”

同主干下，③ 比 ① 好 0.5%~8%；但 PatchTST 点预测 + 同一个残差池在 LOA/SZH 反超 ③。  
**含义**：不要把它讲成“TSFM 主干带来的巨大提升”；真正有用的是逐站直接优化 pinball loss。SZH 点预测 R²≈0.996，残差已经很小，分布头额外引入的拟合噪声反而露出来。

### 结论 2：扩散输在结构，不是没调好

- ④ 的 PICP@90 只有 0.45~0.50（名义 0.90），MPIW 只有 ③ 的 1/3~1/2：**样本太窄**，不是位置错。
- 定位到 DDIM `η=0` 确定性采样后，加 `η=1` 仍救不回来；⑤ 换吸收态结构，条件 CRPS 能追平“满分门卫”的 ④，但**真零格最差**——它不敢一口咬定 0。
- 两个结构迥异的采样器欠离散程度相同 ⇒ 病根在共用的去噪器/训练/跳步预算，不在门卫；继续换扩散花式是盲试。

### 结论 3：零是“状态”，不是噪声；零侧 oracle 很大，但现门拿不到

- 现在零 → 下一小时仍零 84.6%~90.4%；现在正 → 零 0.4%~6.4%。零有强持续性，连续扩散必然把它抹成尾巴。
- 如果**每格都知道真零/非零**（oracle），crpsΣ 可降：
  - MEL −26.9%、LOA −14.8%、JHB −33.7%、SPO −32.1%、SZH −4.3%。
- 但用现有门控只换零原子、正值形状不动：
  - 门 Brier/logloss 明显优于分位头自带原子（MEL .1717/.523 vs .1903/.678），零事件 AUC .76~.83；
  - crpsΣ 最好只有 blend −0.69% MEL / −0.31% LOA；单边硬规则全部 ≤0.7%；激进时反而 +1.6%~2.8%。
- 原因：门在**真非零格**上仍给 p0≈.22 MEL、.178 LOA；CRPS 对“真非零格上留零质量”的惩罚远大于“真零格少留零质量”。卡点是 **precision**，不是 AUC/Brier。
- 全局 `a/0.6` 校准、逐站仿射校准也都失败：Brier 可能变好，但 crpsΣ 在五城全部变差（+0.5%~+4.5%）。

### 结论 4：峰值不可由历史预测，hurdle 输在正值半

- 真正值残差的线性 R²：MEL .254 / LOA .302 / JHB .316 / SPO .123 / SZH .010；
- **峰格**残差 R²：MEL +.219，其余为负（LOA −.402、JHB −.547、SPO −.154、SZH −.066）。
- 正值幅度头能把峰格 MAE 降 25%~46%，但 hurdle 的 crpsΣ 仍输给 ③（MEL +11.4%、LOA +4.4%）：正值幅度头没有比主干点预测更好，且残差池画不出正值的条件形状。
- **含义**：把峰变成 0/1 分类再回归“有多大”，不是正解；保留分位头的正值形状、只动零原子，才是方向上更干净的做法。

### 结论 5：站间相关存在，但当前精度下 CRPS_sum 分辨不出来

- 测试残差的两两相关很弱但为正：ρ̄ .019~.074；`Var(Σr)/ΣVar(r)` = 1.58~8.76；有效站数只有 5~15。
- 所以“站间独立”是错的；但 CRPS_sum 对“联合 vs 独立采样”的差异在 5/6 城 <5%——当前误差由边际位置/尺度主导，联合结构还轮不到说话。
- 只有当方法显式输出整块场景、且边际误差先降下来，CRPS_sum 才可能重新有分辨力。现在把它当第一指标，主要是在惩罚人为选择的耦合方式。

### 结论 6：分位排序是唯一免费且稳定的收益

- 36%~47% 的格子存在分位交叉（SPO 最严重，q90>q95 占 26%）。
- `np.sort(Q)` 后 crpsΣ：MEL −1.8%、LOA −1.4%、JHB −1.0%、SPO −2.4%、SZH −0.1%，且修掉不合理的原子/区间。
- 其余零侧后处理（比例校准、门控、逐站仿射）都没有稳定收益。

## 6. 对下一步的意义

### 推荐 A：收束成论文（性价比最高）

故事可以写成：

> 在零膨胀、强持续的 EV 充电量上，**简单的逐站分位头稳定优于两种扩散式联合生成器**；扩散的失败不是调参，而是零原子表达、欠离散、门控 precision 三个结构问题；同时，常用的边际 CRPS 会被“门控写 0”白送污染，必须配条件 CRPS。

这是一篇“方法对比 + 失败机理”的论文，不需要再发明新模块，和第一篇 CCF-A 的节奏匹配。主表用 ①③④⑤，辅表用排序、条件 CRPS、oracle 零事件、PatchTST 参照。

### 可选 B：只做一次“零膨胀 + 正值分位”的单头方法

- 保留 ③ 的正值形状，只把零原子换成一个 **precision 更高**的零分类器；用 CRPS 直接训练，而不是先分类再拼。
- 但现有证据显示：现门的可达收益 <1%，oracle 是 15%~27%；除非能把“真非零格上的 p0”从 .18~.22 压到接近 0，否则不值得。
- 这是一个高风险、中等工作量的方向，适合学长明确要求“方法创新”时再做。

### 不建议 C：继续换扩散结构 / 继续找峰值特征

- 两种扩散、多个门控、上尾校准、逐站校准都已试过；失败是结构性的，不是缺一个 trick。
- 峰值残差在历史特征上 R²≈0 或负；再加特征大概率还是噪声。

---

## 7. 边界（跟学长交流时要说清）

- 五城、2023-04~09、H=24/48/72；clean mask 去掉了注入式直线段；AMS 不可比。
- ③ 与 ① 的差距在小城接近种子波动（shuffle 未设种子，R² 约 0.01 量级波动）；SZH 基本打平。
- oracle 零事件是**上界**，不是可达结果；门控结论依赖现有特征和训练，不代表“任何更强的零分类器都不行”。
- 站间相关“CRPS_sum 不敏感”是在当前主干/当前点预测精度下成立的；若边际误差大幅下降，需要重跑联合/独立对照。
- 早期“概率模型只剩 5% 空间”的结论作废：那只按（站，小时）分组，是气候学分布；加两个白给条件（工作日/周末、全城预测幅度）后仍有约 14.5% 空间（H=72），但要用参数化分布，不能靠查表。
